# Imagens públicas do Nexus

Esta pasta é publicada junto com o GitHub Pages. Ela **não é o acervo completo**.

## Pode entrar aqui

Somente cópias que sejam, ao mesmo tempo:

- aprovadas pela editoria;
- públicas e adequadas para exibição aberta;
- com autoria/crédito, contexto, data ou período aproximado e local registrados;
- com autorização/licença verificada quando necessária;
- otimizadas para web.

## Não pode entrar aqui

- originais/matrizes de preservação;
- fotos pendentes de triagem;
- fotos com pessoas identificáveis sem autorização ou análise adequada;
- arquivos restritos, sensíveis ou que possam demandar retirada rápida;
- lotes completos de um evento sem curadoria;
- vídeos e arquivos pesados de acervo.

## Estrutura prevista

```text
public/imagens/
├── 2026/
│   ├── ocupacao-sao-lazaro/
│   ├── bingo-estudantil/
│   ├── centros-academicos/
│   └── espacos-e-cotidiano/
└── README.md
```

Use nomes simples e estáveis, sem dados pessoais desnecessários:

```text
2026-09-ocupacao-sao-lazaro-01.webp
2026-bingo-estudantil-credito-nome-01.jpg
```

A ficha de cada imagem deve ser registrada em `docs/catalogo-fotografias.md`. O original fica no acervo privado (Drive, quando a estrutura for criada), e a cópia pública fica aqui.
